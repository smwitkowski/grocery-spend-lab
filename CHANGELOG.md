# Changelog

All notable changes to Grocery Spend Lab are documented here. Releases follow
[Semantic Versioning](https://semver.org/).

## 0.2.0 - 2026-09-16

- Added a versioned, machine-readable CLI contract for agents.
- Added validation, schema discovery, atomic output publication, and hashed manifests.
- Added a portable Agent Skill with privacy and interpretation guidance.
- Added unattended Harris Teeter export preflight and opt-in raw-response retention.
- Added a repository icon and synthetic example output to the project overview.

## 0.1.0 - 2026-09-16

- Added the Harris Teeter browser exporter and local grocery spending analysis.
- Added synthetic fixtures, charts, and initial Python and Node tests.
